# Titanic Survival Analysis

基于 Kaggle Titanic 数据集，使用 Python 对乘客信息进行数据清洗、描述性统计、探索性分析与可视化，分析性别、舱位、年龄等因素与乘客生存情况之间的关系。

## 1. 项目介绍

本项目主要围绕以下问题展开：

- Titanic 乘客数据的基本情况及缺失值情况
- 性别与生存率之间的关系
- 不同舱位与生存率之间的关系
- 不同年龄段与生存率之间的关系
- 性别与舱位的组合与生存情况之间的关系
- 年龄与票价之间的关系

## 2. 数据处理

主要完成以下数据处理工作：

- 查看数据规模、字段、数据类型及缺失值
- 按性别平均年龄填充 `Age` 缺失值
- 删除缺失比例较高的 `Cabin` 字段
- 使用众数填充 `Embarked` 缺失值
- 对清洗后的数据进行进一步分析

## 3. 探索性分析

通过 `groupby()`、`agg()`、`value_counts()`、`pd.cut()` 等方法，对乘客的性别、舱位、年龄等变量进行分组统计，并分析其与生存率之间的关系。

主要发现：

- 女性乘客生存率明显高于男性乘客
- 高等级舱位乘客整体生存率高于低等级舱位乘客
- 不同年龄段乘客的生存情况存在一定差异
- 性别与舱位结合后，可以进一步观察不同乘客群体之间的生存差异
